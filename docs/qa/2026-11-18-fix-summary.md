## bug ที่ร้ายแรงและสิ่งที่แก้

| รหัส | ระดับ | ปัญหา | สิ่งที่แก้ |
|---|---|---|---|
| C1 | critical | path parameter `:id` ของเอกสารถูกส่งเข้า query ตรงๆ | ทุก route ของเอกสาร parse `:id` เป็นเลขจำนวนเต็มบวกด้วย `documentIDParam` ถ้าไม่ใช่ตอบ 400 |
| C2 | high | ไฟล์ผล OCR ไฟล์เดียวเสีย ทำให้ list, search, suggest และ auto-confirm ตอบ 500 ทั้งระบบ | ข้ามเฉพาะเอกสารที่ไฟล์เสียแล้วบันทึก log |
| C3 | high | เอกสารที่ OCR ล้มเหลวบันทึกหรือยืนยันไม่ได้อีกเลย | ผู้ตรวจพิมพ์ข้อมูลเองได้ เฉพาะเอกสารที่ stage เป็น `FAILED` ต้องส่ง `expectedUpdatedAt` และยืนยันไม่ได้ถ้ายังว่าง |
| C4 | high | นำเข้า CSV/XLSX/DOCX แล้วทั้งแถวไปอยู่ในช่องชื่อ | แยกคอลัมน์ตามตำแหน่ง รวมเซลล์ว่างที่ XLSX ไม่เขียนลงไฟล์ |
| C4b | high | auto-confirm ยืนยันเอกสารที่ไม่มีรายชื่อหรือชื่อปนบรรทัด | ไม่ยืนยันอัตโนมัติถ้าไม่มีรายการแต่งตั้ง หรือชื่อมี tab/ขึ้นบรรทัด |
| C5 | high | ยกเลิกการผูกชื่อแล้วบันทึกไม่ได้ ระบบผูกกลับเอง | ยกเลิกแล้วคงไว้เฉพาะเอกสารนั้น |

ข้อ medium และ low ที่แก้ด้วย เช่น อัปโหลดไฟล์ซ้ำพร้อมกันได้ 409 แทน 500, ไฟล์ว่างได้ 400, งาน OCR เก่าเขียนทับไฟล์ที่ถูกแทนที่ไม่ได้, migration รันพร้อมกันได้, หน้า review เตือนก่อนออกเมื่อมีข้อมูลที่ยังไม่บันทึก, ปุ่มบนมือถือไม่ล้นจอ, หน้า 404 ภาษาไทย และอัปเกรด Next เป็น 16.4.6

## ข้อที่ปิดตามการตัดสินใจของเจ้าของระบบ

- **C19 การสแกนใหม่:** คงพฤติกรรมตาม `c040085` คือเก็บ `confirmed_by` / `confirmed_at` ไว้ แก้เอกสารให้ตรงกับโค้ด
- **C5 alias:** ยกเลิกการผูกมีผลเฉพาะเอกสารนั้น ระบบยังจำ alias ไว้ เอกสารอื่นที่ชื่อเดียวกันยังผูกให้เอง มีเทสต์ยืนยัน
- **C15 ปุ่ม Back ของเบราว์เซอร์:** ยังไม่เตือนเมื่อมีข้อมูลค้าง ยอมรับไว้ก่อน (reload, ปิดแท็บ และกดลิงก์เตือนแล้ว)

## ข้อจำกัดที่รู้แล้วและงานต่อ

- ตารางที่แยกชื่อเป็นหลายคอลัมน์ (คำนำหน้า ชื่อ นามสกุล) และแถวลงนามที่มี 3 ช่อง ยังอ่านไม่ถูก
- ข้อความในช่องหน้าที่ที่ยังไม่ได้กด "เพิ่มหน้าที่" หายเมื่อสลับแท็บ (เป็นมาก่อนรอบนี้)
- จาก code review: ตัวตรวจคอลัมน์ของ migration ยังไม่สนเครื่องหมาย quote, โค้ดแทนที่ไฟล์ซ้ำกันสองที่ควรรวมเป็น helper เดียว, dashboard ยิง COUNT หลาย query
- ยังไม่ได้ playtest ซ้ำบนหน้าเว็บที่ build จากโค้ดใหม่
