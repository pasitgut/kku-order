2. รัน fixer ตามแผน G1/G2/G3 ซึ่งรอบนี้ยังไม่มีผลรายงานกลับมา โดยเรียงจาก high ลงมา คือ C2, C3, C4/C4b, C5 แล้วจึง medium
3. ขออนุมัติจาก user ก่อน bump `next`/`eslint-config-next` เป็น 16.4.6 ขึ้นไป (C10)
4. ให้ user ตัดสินใจเรื่อง product/policy: auto-confirm ของ draft ที่คนกำลังตรวจ (playtest-core-3), การอ่าน snapshot ของ UNSAVED (static-audit-4) และ CASCADE ของ confirmation history (static-audit-11)
5. แก้ flaky test C13 เพื่อให้ suite ที่มี DSN ผ่านได้ทุกรอบ
6. ล้างข้อมูลทดสอบที่ค้างใน DB `docflow-baseline` ตามรายการในข้อ 6
